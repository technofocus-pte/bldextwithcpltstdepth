# Laboratoire 3 : Configuration de Dynamics 365 Customer Service

### Tâche 1 : S'inscrire à la version d'essai de Dynamics 365 Customer Service

1.  Connectez-vous à
    +++<https://dynamics.microsoft.com/en-us/customer-service/overview/>+++

2.  Connectez-vous à l'aide d’**Office 365 Tenant details** à partir de
    l' onglet **Home** si vous y êtes invité.

3.  Cliquez sur **Try for free**

![Une personne en gilet et lunettes Description générée
automatiquement](./media/image1.png)

4.  Entrez votre **Office 365 Administrative Username** dans l'onglet
    **Resources**, cochez la case et cliquez sur **Start your free
    trial**

![Une capture d'écran d'un ordinateur Description générée
automatiquement](./media/image2.png)

5.  Entrez la région **United States**, entrez votre **Phone number** et
    cliquez sur **Submit**.

![Une capture d'écran d'un ordinateur Description générée
automatiquement](./media/image3.png)

6.  Si vous voyez une option pour lancer l'essai pour les clients
    Engage, cliquez sur **Launch Trial.**

![Une capture d'écran d'un fond bleu et blanc Description générée
automatiquement](./media/image4.png)
