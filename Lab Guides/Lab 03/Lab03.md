# 实验 02：配置 Dynamics 365 Customer Service

### 任务 1：注册 Dynamics 365 Customer Service 试用版

1.  登录
    +++<https://dynamics.microsoft.com/en-us/customer-service/overview/>+++

2.  如果出现提示，请使用 **Home** 选项卡中的 **Office 365 Tenant**
    详细信息登录。

3.  点击 **Try for free**

![A person in a vest and glasses Description automatically
generated](./media/image1.png)

4.  从**Resources** 选项卡中输入您的 **Office 365 Administrative
    Username**，选中复选框，然后单击**Start your free trial**。

![A screenshot of a computer Description automatically
generated](./media/image2.png)

5.  输入地区 **United States**美国，输入您的**Phone
    number**电话号码，然后单击**Submit**。

![A screenshot of a computer Description automatically
generated](./media/image3.png)

6.  如果您看到 Launch Trial for Engage customers 选项，请单击 **Launch
    Trial**。

![A screenshot of a blue and white background Description automatically
generated](./media/image4.png)
