# ラボ02: Dynamics 365 Customer Serviceの構成

### タスク 1: Dynamics 365 Customer Service のトライアルにサインアップする

1.  +++<https://dynamics.microsoft.com/en-us/customer-service/overview/>+++
    にログインする。

2.  プロンプトが表示されたら、**ホーム**タブから**Office
    365テナント**の詳細を使用してログインします。

3.  **Try for free**をクリックする。

![A person in a vest and glasses Description automatically
generated](./media/image1.png)

4.  リソースタブから**Office 365
    Administrativeユーザ名**を入力し、チェックボックスをオンにして**Start
    your free trial**をクリックする。

![A screenshot of a computer Description automatically
generated](./media/image2.png)

5.  地域を**United States**にして**Phone
    number**を入力し、**Submit**をクリックする。

![A screenshot of a computer Description automatically
generated](./media/image3.png)

6.  Engage customers向けにLaunch Trial
    のオプションが表示された場合**Launch Trial**をクリックする。

![A screenshot of a blue and white background Description automatically
generated](./media/image4.png)
