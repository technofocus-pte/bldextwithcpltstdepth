# 실습 02: Dynamics 365 Customer Service 구성

### 작업 1: Dynamics 365 Customer Service 체험판에 등록하기

1.  +++<https://dynamics.microsoft.com/en-us/customer-service/overview/>+++에
    로그인하세요.

2.  메시가 표시되면 **Home** 탭에서 **Office 365 Tenant details**로
    로그인하세ㅇ.

3.  **Try for free**를 클릭하세요.

![A person in a vest and glasses Description automatically
generated](./media/image1.png)

4.  **Resources**탭에서 O **Office 365 Administrative Username**을
    입력하고, 체크박스를 선택한 후 **Start your free trial**을
    클릭하세요.

![A screenshot of a computer Description automatically
generated](./media/image2.png)

5.  지역을 **United States**으로 설정하고, **Phone number**를 입력한 후
    **Submit**을 클릭하세요.

![A screenshot of a computer Description automatically
generated](./media/image3.png)

6.  Engage 고객을 위한 Launch Trial 옵션이 보이면, **Launch Trial**을
    클릭하세요.

![A screenshot of a blue and white background Description automatically
generated](./media/image4.png)
